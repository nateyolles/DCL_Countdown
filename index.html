This is a countdown timer to your next Disney Cruise Line sail date.

While there's nothing like being on a Disney Cruise, the next best thing is looking forward to one. Now you can watch the little ship endlessly chug along without constantly checking your phone.

Depending on your operating system and browser, you may be able to display this countdown timer in full screen mode, as a picture-in-picture overlay or even as a desktop widget. Rotate the countdown timer to display it in a vertically oriented monitor to more closely resemble the DCL App.

This project is just for fun. It was a personal exercise for programming with AI.

This project is open source, isn't monetized, and has no affiliate links. It doesn't store user information and it doesn't use cookies. There are analytics to monitor uptime and see how many people are using it, but it doesn't track you.

This project is not affiliated with or endorsed by Disney.
